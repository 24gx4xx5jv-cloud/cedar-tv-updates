Cedar Link

Cedar Link adds an end-to-end encrypted bridge from an Apple profile to another Cedar device or the browser companion. It is optional and does not create a Cedar account.

How linking starts

From Cedar Settings, a profile owner creates a short-lived invitation. The invitation carries random enrollment and encryption material in a QR code or browser URL fragment. A URL fragment is not sent to the page host, CDN, or ordinary HTTP request logs.

What the relay can see

The Cedar Link relay handles authenticated ciphertext plus random space and device identifiers, timestamps, authorization, and delivery state. It cannot read the full profile, provider credentials, or companion commands inside those encrypted records.

Narrow browser authority

The browser receives a profile-specific companion key. It can manage presentation, Home shelves, linked-device status, and playback controls, but it cannot decrypt the full native profile snapshot or provider credentials.

Revocation and deletion

The original Cedar device can review linked installations and revoke one immediately. The owner can delete the linked profile in Cedar to remove the entire Cedar Link space. Do this before uninstalling: uninstalling first removes only local data. Data already stored locally on another linked device remains until removed there.

Open only invitations you created

The companion needs a fresh invitation generated by Cedar. Do not paste a pairing link into chat, email it to an untrusted person, or open a link you did not create.
