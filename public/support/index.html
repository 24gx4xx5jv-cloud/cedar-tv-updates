Cedar support

Let’s get you unstuck.

Start with the checks below. If the problem continues, contact the Cedar community with the app version, platform, and a safe description of what happened.

Before you contact support

  1. Confirm the source works in its official client or web page.
  2. Use Cedar’s source refresh and connection check.
  3. Try HTTPS when the server supports it.
  4. Record the Cedar version, platform, and exact action that failed.

Contact Cedar

Ask for help, report a bug, or suggest an improvement through the Cedar Discord community or the public GitHub issue tracker. Do not post provider credentials, private playlist addresses, pairing codes, customer data, or unredacted logs.

Share safe diagnostics

Enable diagnostics only while reproducing the issue, then export the report yourself. Cedar redacts known passwords, tokens, signed playback paths, and sensitive URL parameters. Review every export before sharing it.

Content and account questions

Cedar cannot restore a provider account, subscription, playlist, or stream. Contact that service directly. Cedar supplies no media and cannot help locate unauthorized sources.

Privacy requests

Cedar has no developer-operated user-account database. Disconnect services, remove local profiles, or delete Cedar to manage local app-container data. Revoke Cedar Link devices or delete the linked profile to remove an active relay space. For a sensitive concern, contact a Cedar moderator privately rather than posting personal information in a public channel.

Read Cedar’s privacy policy

Cedar Link help

Cedar Link uses a short-lived invitation to connect another Cedar device or a browser. Never share a pairing link or code. If a device is lost or no longer trusted, revoke it from Cedar Settings.

Accessibility help

Include your Cedar version, Apple platform, assistive technology, and the screen or task where a barrier occurred. Do not include account or provider credentials.

Response expectations

Cedar is community-supported. Include enough detail to reproduce the issue and allow time for a volunteer response. Clearly label security or privacy concerns and never include a live credential.
