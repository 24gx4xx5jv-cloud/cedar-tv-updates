Content Policy

Cedar is a player and organizer. It provides no movies, shows, channels, playlists, manifests, subscriptions, or provider credentials.

Bring only authorized sources

Connect only media and services you own, operate, or are authorized to access. You are responsible for following the terms of every source and service you connect.

No source directory or resale

Cedar does not sell subscriptions, recommend unlicensed providers, scrape protected services, run a streaming proxy, support peer-to-peer delivery, or execute third-party plug-ins. Manifest and playlist responses are data from endpoints a user chooses.

Downloads

Cedar offers downloads only when a configured source provides a downloadable copy. The user is responsible for having permission to download and retain that media.

Metadata and trailers

This product uses TMDB and the TMDB APIs but is not endorsed, certified, or otherwise approved by TMDB. Metadata may also be provided by TheTVDB. Trailer links open externally in YouTube or the system browser only after the user chooses one.
