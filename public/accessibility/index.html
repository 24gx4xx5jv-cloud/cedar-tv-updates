Accessibility

Cedar should work with the way you use your Apple devices.

Cedar is built with native Apple interface controls across iPhone, iPad, Apple TV, and Mac. Accessibility support is evaluated around complete, common tasks before any App Store accessibility claim is selected.

Screen readers and focus

Cedar supplies spoken labels for image-only controls and aims to keep navigation order aligned with the visible interface. Apple TV uses the system focus engine, and Mac surfaces retain keyboard focus where native controls provide it.

Text and contrast

Cedar uses Apple text styles and semantic colors where the platform allows. The interface supports system light and dark appearances. Release validation covers larger text, clipping, contrast, and meaning that depends on color across common flows.

Motion and interaction

Cedar checks the system Reduce Motion setting before optional motion effects and avoids requiring a gesture when a visible control can perform the same task. Candidate validation reviews controls for platform-appropriate target size and remote focus.

App Store accessibility information

Cedar publishes an App Store accessibility claim only after every common task for that feature passes on the relevant release build. Platform claims may differ because iPhone, iPad, Apple TV, and Mac use different controls and input methods.

Report an accessibility barrier

Include the Cedar version, Apple platform, assistive technology, and exact task or screen. Never include a provider password, token, playlist address, or Cedar Link invitation.

Contact Cedar support

Release validation

The release checklist covers first launch, source setup, Home and library browsing, search, playback controls, Settings, privacy information, and device-link management with the assistive technologies available on each platform. Validation is not complete until those tasks pass on final release builds.
